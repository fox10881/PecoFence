# 💠 CoreDesk Engine — 究極のデスクトップカスタマイズ＆整理スイート

**Windows 11 を、息づく超整理されたガラスのワークスペースに変える。**

CoreDesk Engine は Rust 製の次世代デスクトップ整理＆Windows 11 シェルカスタマイズスイート。単純なアイコンフェンスを遥かに超え、磁石式デスクトップ整理、3D パースペクティブ棚、ライブ H.264 動画壁紙、適応型デスクトップ時計ウィジェット、Windows 11 シェルの深いテーマ化（タスクバー、スタートメニュー、通知センター、エクスプローラーの Mica/Acrylic）、そしてワンクリック `.cde` フルテーマパッケージを統合する。

## ✨ このエディションが特別な理由

CoreDesk Engine のすべての層が再設計され、デスクトップアイコンと Windows 11 シェルそのものへの完全な創造的自由を与える — CPU/GPU 使用率はほぼゼロのまま。

---

## 🎨 1. 次世代フェンススタイルとビジュアルブレンド

4 つの異なるビジュアルパラダイムで標準コンテナを超える：
- **Fluent（クラシック）：** クリーンな Windows 11 Fluent カードとシャープな境界線。
- **Liquid Glass：** 静止画やライブ動画壁紙をサンプリングするリアルタイム屈折ガラス。
- **Bookshelf（`رف الكتب`）[新規]：** フェンスを立体的な棚に変え、アイコンが棚の段にきれいに並ぶ。
- **Invisible Canvas（`لوحة غير مرئية`）[新規]：** フェンスの背景と枠を完全に隠す — 磁石スナップ、ソートルール、グリッド整列の力はそのままに、アイコンが裸の壁紙に自然に浮かんで見える。

### 🦎 カメレオンアイコンブレンドとショートカット整理
- **カメレオンモード（`دمج الأيقونات مع الخلفية`）[新規]：** **ブレンド強度スライダー（0%–100%）**でアイコンを動的に減色して壁紙に溶かし込み、落ち着いた気が散らない美学を作る。
- **ショートカット矢印トグル（`إظهار/إخفاء أسهم الاختصارات`）[新規]：** 設定から Windows の散らかったショートカット矢印を即座に剥がす・戻す。
- **完全アラビア語ローカライズと RTL UI [新規]：** ネイティブなアラビア語インターフェース（`العربية`）とシームレスな右から左レイアウト、即座のライブ言語切替。

## 🎬 2. ネイティブ H.264 動画壁紙と適応型時計ウィジェット

### 🎞️ ハードウェアアクセラレーション動画壁紙エンジン [新規]
- 任意の **MP4 (H.264)** 動画を、バターのように滑らかなライブ壁紙として CoreDesk Engine から直接設定。
- *CloudConvert* と *FreeConvert* への内蔵クイックリンクで、あらゆる動画を超軽量 GPU フレンドリーな壁紙に変換するのが簡単。

### 🕰️ フレームレスデスクトップ時計ウィジェット（`ويدجت الساعة المكتبية`）[新規]
- **20 の手作りレスポンシブ時計/日付/曜日デザイン**（Gemini 署名 10 + Devin 署名 10）から選ぶか、`بدون` で完全に消す。
- **真のフレームレス操作：** タイトルバーなしで整理された見た目。ウィジェット内の**どこでも**ドラッグで移動、**任意の端/角**を掴んで自動文字スケーリング付きで滑らかにリサイズ。
- **適応型壁紙コントラスト（`تنسيق ألوان الويدجت تلقائياً لتناسب الخلفية`）[新規]：** CoreDesk Engine は時計ウィジェットの真後ろの正確な壁紙ピクセルを継続サンプリング。壁紙が眩しい白でも真っ黒でも、テキスト・ガラス・アクセントのコントラストを自動反転し、時刻と日付が常に 100% 鮮明に読める。

## 📐 4. フェンス単位の精細なカスタマイズと 3D パースペクティブ棚

すべてのフェンスが **フェンス（`الأسوار`）**タブでピクセル単位まで調整可能：

- **フェンス設定の複製（`نسخ الإعدادات من سياج آخر`）[新規]：** 完璧なフェンスを設計した？ワンクリックで外観とレイアウト設定全体を別のフェンスにコピー — 対象の名前・内容・ソートルールは上書きしない。
- **タイトルバー表示（`إظهار شريط العنوان`）：** *常時* と *ホバー時* に加えて **「非表示にする」（`عدم الإظهار أبداً`）[新規]** を追加 — 完全にヘッダーレスの外観に。
- **カスタムアイコンフレームとカラーパレット（`إطارات الأيقونات`）[新規]：** 個別アイコンを **透明（`شفاف`）** または **フルカラー（`ملون بالكامل`）** の角丸カードで包み、**テキスト色（`لون النص`）** と **フレーム色（`لون الإطار`）** の専用 11 色ピッカー付き。
- **密着アイコンモード（`شكل الأيقونة: ملتصق`）[新規]：** アイコンをエッジ・トゥ・エッジの `2:3` ポスターに切り抜き — ゲームライブラリやメディアフェンスに最適！
- **精密ピクセルスライダー [新規]：**
  - **カスタムアイコンサイズ（`حجم أيقونة مخصص`）：** `16px`–`512px` の自由スライダー。
  - **列間隔（`تباعد الأعمدة`）＆行間隔（`تباعد الصفوف`）：** `0px` まで詰めてアイコンを隙間なく接触させるか、`48px+` まで広げる。
- **スクロールバー制御 [新規]：** **スクロールバーを隠す（`إخفاء شريط التمرير`）**を独立して切替（マウスホイールスクロールは有効のまま）、または **スクロールロック（`قفل التمرير`）**で内容を上部に固定してショーケースレイアウトに。
- **3D 傾斜棚モード＆パースペクティブスケール（`وضع الرف المائل` + `معامل التكبير`）[新規]：** フェンスを 3D パースペクティブ平行四辺形に傾け、角度のある 3D 部屋壁紙に合わせる！**パースペクティブスケール係数（`معامل التكبير`）**を調整してアイコンが棚の遠い端へ滑らかに縮小するリアルな奥行きを実現。

## ⚡ 5. カラーコードソートエンジンと強制適用

**ソートルール（`قواعد الفرز`）**エンジンが信頼性と視認性のために完全に再構築された：
- **カラーコードフェンスバッジ [新規]：** ルール一覧内で各フェンスに固有のカラーバッジが割り当てられ、どのルールがどのフェンスへ向かうか一目で識別できる。
- **今すぐ適用 vs 強制適用（`تطبيق إجباري على كل العناصر`）[新規]：**
  - **今すぐ適用（`تطبيق الآن`）：** 手動配置した項目を尊重しつつ、未整理のデスクトップ項目をそっとルーティング。
  - **強制適用（`تطبيق إجباري`）：** すべての手動配置を上書きし、デスクトップ上の全項目をアクティブなルールに厳密に従って容赦なく再ソート。
- **ワンクリッククイックプリセット（`إضافة سريعة`）：** *画像、音楽、動画、アーカイブ、インストーラー*、または *デスクトップクリーンアップ*（30 日以上触れていないインストーラーとアーカイブのみを掃き集め、ファイルは一切削除しない）のフェンスとルールを即座に生成。

## 📦 6. `.cde` 完全テーマパッケージとスマート壁紙フィット

基本的な `.json` レイアウトバックアップは忘れよう — **レイアウト＆バックアップ（`التخطيط والنسخ الاحتياطية`）**タブは今や完全な**ビジュアルテーマギャラリー（`معرض الثيمات`）**：
- **オールインワン `.cde` テーマアーカイブ [新規]：** テーマを保存すると**すべて**がポータブル `.cde` バンドルに収録 — フェンスの正確な座標、フェンス別スタイル、カスタムアイコンサイズ、ソートルール、ガラス設定、そして静止画またはライブ動画壁紙。自動デスクトッププレビューサムネイル付き！
- **ワンクリック適用・エクスポート・インポート：** 数秒でデスクトップ全体のセットアップを切替、または `.cde` をエクスポートして誰とでもテーマを共有。
- **スマートアスペクト比壁紙フィット（`ضبط الصورة لتظهر بالكامل مهما كانت أبعاد الشاشة`）[新規]：** モニターの縦横比に合わない壁紙がある？オンにすると画面中央にトリミングなしの全画像を表示し、端を雰囲気のあるぼかし背景で埋める — オフで標準のエッジ・トゥ・エッジクロップフィルに。
- **毎日自動保存（`حفظ تحديث الثيم تلقائياً كل يوم`）[新規]：** アクティブな `.cde` テーマファイルを 1 日 1 回その場で自動更新 — 最新のデスクトップ調整が重複なしで常に保存される。

## 🚀 はじめに

1. **Releases** ページから最新の `setup.exe` または `portable.zip` をダウンロード。
2. システムトレイから **CoreDesk Engine** を起動し、**設定（`إعدادات CoreDesk Engine`）**を開く。
3. **テーマスタイル**（*Fluent, Liquid Glass, Bookshelf, Invisible Canvas*）を選ぶか、**デスクトップ時計ウィジェット**を有効にするか、**テーマギャラリー**から `.cde` テーマをインポート — デスクトップが即座に変貌するのを目撃しよう！
