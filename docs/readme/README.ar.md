### 🧩 القطعة الناقصة الأساسية: BoxArt Studio
يوفر PecoFence التخطيط الشبكي المنظم وحاويات الملصقات بنسبة 2:3 دون فواصل، لكن Windows ما زال يُنشئ أيقونات مربعة قياسية.
للحصول على المظهر الدقيق لرف الألعاب المادي الموضح في لقطة الشاشة، تحتاج إلى **[BoxArt Studio](https://github.com/fox10881/BoxArt-Studio)‏**. BoxArt Studio هو الأداة المرافقة الأساسية التي تحوّل اختصارات ألعاب Windows ومجلداتك دفعةً واحدة إلى علب ألعاب أنيقة عالية الدقة بنسبة 2:3.

## سطح مكتبك. بتكوين ذكائك الاصطناعي

**سطر أوامر مدمج. جاهز لوكيل الذكاء الاصطناعي.**

أخبر وكيل الذكاء الاصطناعي كيف تريد أن يعمل سطح مكتبك. يتيح `pecofence-cli` المرفق لـ Claude Code وCodex وCursor قراءة إعداداتك الحالية وتطبيق التغييرات مباشرةً في PecoFence.

- **اضبطه بكلماتك الخاصة.** غيّر السمات والشفافية وأحجام الأيقونات والإعدادات العامة، أو عدّل جميع السياجات دفعة واحدة.
- **نظّم مرة واحدة. وابقَ منظمًا.** أنشئ سياجات للمشاريع، ورتّب الأيقونات، وأضف قواعد تفرز الملفات الجديدة تلقائيًا.
- **احفظ الإعداد الذي يعجبك.** استخدم اللقطات لحفظ تخطيطات السياجات، وتصدير/استيراد التكوين للإعدادات والقواعد والتخطيطات.

**جرّبه مع وكيل الذكاء الاصطناعي لديك**

افتح PecoFence، ثم الصق هذا الطلب في وكيل البرمجة الخاص بك:

> استخدم pecofence-cli لتكوين سطح مكتبي. اقرأ أولاً pecofence-cli skill وpecofence-cli describe، ثم افحص إعداداتي وسياجاتي الحالية. انسخ تكويني احتياطيًا قبل التغييرات. بدّل إلى الوضع الداكن واجعل جميع السياجات أكثر شفافية.

سطر الأوامر مضمّن مع التطبيق. إصدار Microsoft Store يضيف `pecofence-cli` إلى متغير PATH. ومع النسخة المحمولة ZIP، أعطِ وكيلك المسار الكامل إلى `pecofence-cli.exe`.

<details>
<summary><strong>مثال على محادثة مع وكيل برمجة</strong></summary>

> ضع ملفات PDF على سطح مكتبي في سياج Docs، واحتفظ بملفات PDF الجديدة هناك، وبدّل إلى الوضع الداكن واجعل السياجات أكثر شفافية.

```powershell
pecofence-cli config export "$env:USERPROFILE\pecofence-before-ai.json"
pecofence-cli snapshot save before-cleanup
pecofence-cli fence create --title Docs
pecofence-cli rule add --name PDFs --ext pdf --to Docs --index 0
pecofence-cli rule apply
pecofence-cli settings set theme dark
pecofence-cli fence set --all opacity clear
```

</details>

مصمم للوكلاء والنصوص البرمجية: `describe` يعرض فهرس الأوامر ومخططات JSON Schema؛ و`skill` يطبع دليل الاستخدام. تُبلغ نتائج JSON عمّا تغيّر، وتساعد الأخطاء المهيكلة الوكيل على اختيار خطوته التالية.

## شاهدها أثناء العمل

### سياج واحد. مساحات عمل متعددة.

اجمع السياجات المترابطة في علامات تبويب. بدّل من «المشروع» إلى «الأفكار» بنقرة واحدة،
ثم اسحب علامة التبويب للخارج عندما تحتاج مساحة إضافية.

![دمج سياجين في علامتي تبويب، والتبديل بين «المشروع» و«الأفكار»، ثم سحب علامة تبويب للخارج لتصبح سياجًا مستقلًا.](../assets/tabs.gif)

### سطح مكتبك على بُعد اختصار واحد.

اضغط **Ctrl + Alt + Space** لإظهار سياجاتك فوق التطبيق الحالي.
خذ ما تحتاجه، ثم اضغط **Esc** للعودة.

![النظرة السريعة تُظهر سياجاتك فوق التطبيق؛ نقرة خارجه أو فتح ملف تعيدك إليه.](../assets/peek.gif)

## تفاصيل صغيرة تصنع فرقًا

| الميزة | ما تحصل عليه |
| :--- | :--- |
| **AI + CLI** | `pecofence-cli` — **اضبطه بكلماتك الخاصة.** غيّر السمات والشفافية وأحجام الأيقونات والإعدادات العامة، أو عدّل جميع السياجات دفعة واحدة. |
| **فرز أقل** | قواعد لأنواع الملفات والامتدادات والأسماء وأحرف البدل وأهداف الاختصارات والوقت والحجم. تجد الملفات الجديدة سياجها تلقائيًا. |
| **زجاج يناسب سطح مكتبك** | سمتا Fluent وLiquid Glass، وضعا فاتح/داكن، ألوان وشفافية وتلوين أيقونات لكل سياج على حدة. |
| **تعامل مألوف مع الملفات** | قوائم سياق مستكشف الملفات، وسحب وإفلات، ونسخ/لصق، وتحديد متعدد، ومصغرات، وعروض أيقونات/قائمة/تفاصيل. |
| **مجلداتك في متناول يدك** | ضع مجلدًا حيًّا على سطح مكتبك. تصفّح المجلدات الفرعية وشاهد التغييرات فور حدوثها. |
| **مساحة عندما تحتاجها** | لفّ السياج حتى شريط عنوانه. مرّر المؤشر فوقه ليتوسع. اقفل التخطيط الذي يعجبك. انقر نقرًا مزدوجًا على سطح المكتب لإخفاء السياجات، ونقرة مزدوجة أخرى لإظهارها. |
| **طريق للعودة** | لقطات التخطيط، والنسخ الاحتياطية اليومية، واستيراد/تصدير التكوين، وتبديل السياجات بين الشاشات. |
| **حجم صغير** | تطبيق Rust أصلي يستهلك نحو 40 ميغابايت من الذاكرة في وضع الخمول وفق مدير المهام. لوحة الإعدادات بـ WebView2 تُحمَّل عند الطلب فقط. |

قواعد الفرز التلقائي تُبقي الملفات في مواقعها الأصلية. أما نقل الملفات الذي تبادر إليه
فيعمل كما في مستكشف الملفات.

## احصل على PecoFence

<a href="https://apps.microsoft.com/detail/9MV6WG3XNWSX?mode=direct"><img src="https://get.microsoft.com/images/ar%20dark.svg" alt="احصل عليه من Microsoft Store" width="200"></a>

إصدار Microsoft Store موقّع من Microsoft، ويتحدث تلقائيًا، ولا يُظهر أبدًا تنبيه SmartScreen. يتوفر التطبيق نفسه أيضًا بالأشكال التالية:

- **نسخة محمولة ZIP**: نزّل `pecofence-v<version>-x64-portable.zip` من صفحة **Releases** في هذا المستودع، واستخرج **محتويات ZIP كاملة** في مجلد، ثم شغّل `pecofence.exe`.
- **المثبّت**: `pecofence-v<version>-x64-setup.exe` في الصفحة نفسها يثبّت PecoFence لمستخدم Windows الخاص بك، مع إدخال في قائمة «ابدأ» وبرنامج إلغاء تثبيت.
- **winget**: `winget install DayuanJiang.PecoFence` يثبّت النسخة المحمولة ويتجاوز تنبيه SmartScreen.

<details>
<summary><strong>المتطلبات والتكوين وبعض الملاحظات المفيدة</strong></summary>

- Windows 10 الإصدار 22H2، أو Windows 11 الإصدار 22H2 أو أحدث. تتطلب الإعدادات مكون Microsoft Edge WebView2 Runtime. يتضمنه Windows 11 افتراضيًا؛ وعلى Windows 10 ثبّته من Microsoft إذا لم تُفتح الإعدادات.
- عند التشغيل الأول يُنشئ التطبيق أربعة سياجات بلغتك المختارة: البرامج، والمجلدات، والملفات والمستندات، وسطح المكتب. تُستعاد أيقونات سطح مكتب Windows عند الخروج.
- يُحفظ التكوين في `%APPDATA%\PecoFence\config.json`. شغّل بـ `--portable` ليُحفظ في مجلد `config` بجانب الملف التنفيذي.
- ملف ZIP والمثبّت غير موقّعين. إذا ظهر تنبيه Windows SmartScreen عند أول تشغيل، اختر **مزيد من المعلومات ← التشغيل على أي حال**.

</details>
